# Supermarket Sales Analysis

## Project Overview

This beginner-level Excel project analyzes supermarket sales data using Microsoft Excel, PivotTables, charts, and a dashboard.

The dashboard provides an overview of sales performance, transaction volume, quantity sold, product lines, cities, and payment methods.

## Tools Used

- Microsoft Excel
- Excel Tables
- PivotTables
- PivotCharts
- Excel Dashboard

## Files Included

- `Supermarket Sales Analysis .xlsx` — Excel workbook containing the analysis, PivotTables, charts, KPIs, and dashboard.
- `supermarket_sales - Sheet1.csv` — Original supermarket sales dataset.
- `Supermarket Sales Dashboard Preview.png` — Preview image of the completed dashboard.

## Analysis Performed

The project includes analysis of:

- Sales by product line
- Sales by city
- Sales by payment method
- Quantity sold by product line
- Key performance indicators
- Dashboard visualizations

## Key Learning Outcomes

Through this project, I practiced:

- Importing and organizing sales data
- Creating Excel Tables
- Building PivotTables
- Creating charts from PivotTables
- Designing a basic business dashboard
- Presenting business insights visually

## Project Objective

The objective of this project is to understand how Excel can be used to organize business data, identify sales patterns, and communicate findings through an interactive dashboard.
